使用说明DXF ⇄ DWG 互转
  1. 选择文件：左侧浏览本机目录，勾选 .dxf / .dwg（支持多选），点「加入转换队列」；也可以直接粘贴文件完整路径。
  2. 输出地址：默认输出到「源文件所在文件夹」。需要改位置时，在右侧选「手动指定文件夹」并浏览选择；队列里每个文件也能单独点「更改」。
  3. 输出文件名：默认与原文件完全同名，只把扩展名换成目标格式。可在队列中逐个编辑，或用「可选后缀」批量加后缀。
  4. 开始转换：底部按钮执行批量转换，进度与结果实时显示；若目标文件已存在会先询问处理方式。
  5. 拖拽添加：把左侧列表里的文件行直接拖进中间队列即可；也可以从资源管理器把 .dxf / .dwg 拖到页面任意位置。
为什么用内置文件浏览器？：网页出于安全限制拿不到系统选文件对话框返回的真实磁盘路径，也就无法做到「默认输出到源文件所在文件夹」。本工具在本地起一个服务，用可视化目录浏览来选文件，因此能准确记住每个文件的原始目录。
拖拽的两种情形：拖左侧列表项属于工具内部拖拽，能带上真实路径，默认仍输出到源文件夹；从资源管理器拖进来的文件浏览器只给出文件名和内容，工具会把它暂存到本机 uploads\，并弹出目录选择框请你指定输出地址（不指定则输出到工具目录下的「转换输出」）。拖入文件夹暂不支持，请用左侧目录浏览。
格式方向：.dwg → .dxf、.dxf → .dwg 自动判断，无需手动指定。
预览：DXF 直接解析渲染；DWG 会临时转成精简 DXF 渲染，不会修改原文件。
为什么转换后彩色标注线会消失？：黄/绿这类线条往往属于「块定义」——尺寸标注的线、箭头、文字，以及复制进来的匿名块。内置 LibreDWG 用 R2000 及以下版本输出 DXF 时会把块写成空块，图形随之消失。工具现已默认「自动（跟随源 DWG）」，并在检测到块被清空时自动按源版本重出，转换日志会写明。
兼容性：内置 LibreDWG 对 DWG 的写入支持到 R2000/R2004，读 R2007 及以上 DWG 时也可能丢失部分图层引用与显式颜色（图元会退化为白色 0 层）。复杂三维实体、代理对象、高版本特性同样可能丢失。重要图纸建议安装 ODA File Converter 并在「转换参数」中选用。
隐私：全部转换在本机完成，服务只监听 127.0.0.1，不上传任何文件。
开源组件：转换内核为 GNU LibreDWG 0.14（GPLv3 或更高版本），随工具附带其原始 Windows 二进制与说明文件。
